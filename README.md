# Monthly demo — Reltio IDE Git integration

Sample business configuration repository for a Reltio IDE demo.

Reltio IDE discovers `BusinessConfig.json` automatically. Use **Add Config** in Explorer for `extra/L3.json`.

| Path | What it is |
|---|---|
| `life-sciences/BusinessConfig.json` | Life Sciences configuration |
| `insurance/BusinessConfig.json` | Insurance configuration |
| `extra/L3.json` | Valid business configuration, not named `BusinessConfig.json` |
